# 流水核验台（MVP 原型）

这是面向银行客户经理的本地工具。双击 `start.bat`，然后在浏览器打开 `http://127.0.0.1:5000`。首次使用前请执行 `py -m pip install -r requirements.txt`。

## 已实现

- 文本型流水 PDF 上传、页数与文本提取
- 借款人行业、经营描述采集
- 基于交易对手、交易方向、金额/频率特征的经营关联展示
- 可追溯的逐笔判定、待核实事项、CSV 导出
- 明确的人工复核与授信合规提示；上传文件只在服务进程内存中解析，不落盘

## 部署到 Streamlit Cloud

1. 在 GitHub 新建一个私有仓库，并将此目录中的项目文件推送至该仓库。
2. 登录 [Streamlit Community Cloud](https://share.streamlit.io/)，选择 **Create app**，关联该 GitHub 仓库。
3. 将入口文件设置为 `streamlit_app.py`，点击部署。
4. 发布后得到 `https://<应用名>.streamlit.app`；可在手机或电脑使用该地址。

本地测试 Streamlit 版：先运行 `py -m pip install -r requirements.txt`，再双击 `start-streamlit.bat`。

Streamlit Cloud 适合试用。处理真实流水或向不特定用户开放前，请至少增加账户访问控制；上传文件会经 Streamlit 云端处理。

## 上生产前必须补齐

1. 接入受控的 PDF 文本提取与 OCR（扫描件），并保存每笔交易的原文件页码、坐标和哈希。
2. 为各银行、微信/支付宝导出模板建立版本化解析器；解析失败时必须人工校验，不能静默猜测。
3. 将当前演示规则替换为可配置的规则引擎：行业关键词、收支对手、金额区间、频率、季节性和异常模式，并保留规则命中证据。
4. 增加客户授权、最小权限、传输与存储加密、访问审计、数据保留/销毁策略；不要将未脱敏流水交给公共第三方模型。
5. 接入反洗钱、关联方、黑名单等银行内部系统，并将“模型建议”和“人工结论”分开留痕。

## 建议技术路线

浏览器/柜面前端 → 行内文件服务 → PDF/OCR 解析服务 → 交易标准化 → 规则+模型评分 → 人工复核与审计报告。

生产版应部署在银行内网或获批的数据域中；本原型不上传文件，也不包含真实 PDF/OCR 解析能力。# AnalyseFlow
